## ✎ᝰ. RUNNING

- Clone Repository

```bash
git clone https://github.com/Hunga9k50doker/stork.git
cd Stork
```

- Install Dependency

```bash
npm install
```

- Setup config in config.js

- Setup input value

* proxy: http://user:pass@ip:port

```bash
nano proxy.txt
```

- account: email|password

```bash
nano accounts.txt
```

- Run the script

```bash
node main.js
```
